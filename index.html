Why it works so well on pixel art

Pixel art uses few colors and large flat areas. That lets each file be stored with an exact color palette and fewer bits per pixel, which usually cuts the size by more than half with zero quality loss. Photos and painted art don't have those properties, so they shrink much less.

Tips for Aseprite exports

  • Export at 100% scale and let the game engine upscale with nearest-neighbor filtering. A sprite exported at 800% has 64 times more pixels to store.
  • Keep your .aseprite files as the source; this tool only touches the exported PNGs.

Your images never leave your computer. Everything is processed in this browser; nothing is uploaded to any server.

Compression is lossless: every file is compared pixel by pixel with the original before you get it. If it isn't identical or isn't smaller, you get the original back.
